# 🚀 DevLens

A modern GitHub Developer Analytics Dashboard built with **HTML, CSS, and Vanilla JavaScript**.

DevLens allows users to search GitHub profiles, explore repositories, and keep track of recently searched developers through a clean glassmorphic interface.

---

## ✨ Features

- 🔍 Search any GitHub user
- 👤 View developer profile information
- 📊 Display followers, following, and repository count
- 📂 Browse the latest repositories
- 🔗 Visit GitHub profile or repositories directly
- 🕒 Recent Searches with Local Storage
- 🎨 Modern Glassmorphism UI
- 🔔 Toast Notifications
- 📱 Responsive Design

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- GitHub REST API
- Local Storage
